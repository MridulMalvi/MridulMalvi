## Featured Projects

### 🔹 [Rexona AI - Multi-Agent Intelligence Engine](https://github.com/MridulMalvi/rexona-ai)
> A fully local, privacy-first AI assistant with multi-agent orchestration, RAG over documents, and persistent memory, with zero external API costs.

Built with `LangGraph` · `Ollama (Qwen2.5)` · `FAISS` · `Nomic-Embed-Text` · `Streamlit`

**Highlights:** Semantic search over uploaded PDFs via PyPDFLoader + FAISS · Autonomous tool-calling LLM · Persistent conversational memory across 10+ concurrent threads via InMemorySaver

---

### 🔹 [FinSight - Stock Prediction & News Intelligence Engine](https://github.com/MridulMalvi/FinSight)
> A multi-horizon stock-direction forecaster that combines technical indicators with company-aware financial news analysis to predict UP, NEUTRAL, or DOWN moves.

Built with `Python` · `FastAPI` · `XGBoost` · `LightGBM` · `NLP` · `SMOTE`

**Highlights:** Soft-voting XGBoost + LightGBM ensemble trained on 44,658 sessions across 10 Indian equities and ETFs · 43 technical and news-sentiment features · SMOTE and per-class threshold calibration for over 30% recall on every class · 1-day to 1-month forecasts · FastAPI backend with RBAC, usage quotas, and audit logging

---

### 🔹 [ExoHabitAI - Exoplanet Habitability Predictor](https://github.com/MridulMalvi/exohabitai)
> An end-to-end ML web app that predicts whether an exoplanet could support life, trained on 9 planetary and stellar features, with an interactive Plotly.js dashboard.

Built with `Python` · `Scikit-learn` · `Imbalanced-learn` · `Flask` · `Plotly.js` · `Gunicorn`

**Highlights:** Random Forest classifier on an imbalanced dataset, handled with imbalanced-learn · Flask REST API deployed on Render for real-time predictions · Habitability gauges, radar charts, and decision-boundary visualizations that make each prediction easy to interpret
